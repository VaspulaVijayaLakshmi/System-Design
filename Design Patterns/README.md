# Design Patterns Categories

| Category | Purpose | Common Design Patterns |
|----------|---------|------------------------|
| **Creational** | Deals with object creation | Singleton, Factory, Factory Method, Abstract Factory, Builder, Prototype |
| **Structural** | Deals with composition of classes and objects | Adapter, Decorator, Facade, Composite, Bridge, Proxy, Flyweight |
| **Behavioral** | Deals with communication, responsibilities, and behavior of objects | Strategy, Observer, Command, State, Template Method, Chain of Responsibility, Mediator, Memento, Iterator, Visitor |

---

## Easy Way to Remember

### 🏗️ Creational
**Question:** *How do I create objects?*

- Singleton
- Factory
- Factory Method
- Abstract Factory
- Builder
- Prototype

---

### 🧩 Structural
**Question:** *How do I connect or compose objects?*

- Adapter
- Decorator
- Facade
- Composite
- Bridge
- Proxy
- Flyweight

---

### 🔄 Behavioral
**Question:** *How do objects communicate or change behavior?*

- Strategy
- Observer
- Command
- State
- Template Method
- Chain of Responsibility
- Mediator
- Memento
- Iterator
- Visitor
