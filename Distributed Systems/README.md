            | Concept              | One-Line Definition                                      |
| -------------------- | -------------------------------------------------------- |
| Replication          | Keep multiple copies of data                             |
| Sharding             | Split data across nodes                                  |
| Consistent Hashing   | Distribute keys while minimizing movement                |
| Redis Cluster        | Uses 16,384 hash slots for partitioning                  |
| Leader-Follower      | One leader coordinates, followers replicate              |
| Quorum               | Minimum number of nodes needed for an operation/decision |
| Consensus            | Distributed nodes agree on a consistent state            |
| Leader Election      | Select one leader among distributed nodes                |
| Distributed Lock     | Ensure only one process accesses a resource at a time    |
| Cache Stampede       | Many requests simultaneously miss cache                  |
| Request Coalescing   | Combine concurrent requests for the same missing key     |
| Kafka                | Distributed event streaming platform                     |
| Outbox               | Reliably publish DB changes as events                    |
| CQRS                 | Separate write and read models                           |
| Materialized View    | Store precomputed query results                          |
| Denormalization      | Duplicate data to optimize reads                         |
| Eventual Consistency | Replicas/read models become consistent over time         |
